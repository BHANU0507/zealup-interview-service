COURSE CONTROLLER API REFERENCE
Base Path: /api/courses

====================================================================
1) LIST COURSES
====================================================================
Method: GET
Path: /
Full Endpoint: /api/courses/

What it does:
- Returns course cards for homepage.
- If user_id is provided, response includes user plan info and enrollment count.
- Decides button action per course:
  - ENROLL
  - CONTINUE_LEARNING
  - PREVIEW

Input:
- Query Params:
  - user_id (optional, string)
  - limit (optional, int, default=20, min=1, max=100)

Output (CourseListResponse):
- user_id: string | null
- plan_name: string | null
- course_limit: int | null
- enrolled_count: int | null
- courses: [
    {
      course_id: string,
      title: string,
      instructor_name: string,
      progress_percentage: int,
      level: string,
      duration_hours: float,
      key_technologies: string[],
      action: string
    }
  ]


====================================================================
2) GET USER ENROLLMENTS
====================================================================
Method: GET
Path: /user-enrollments/{user_id}
Full Endpoint: /api/courses/user-enrollments/{user_id}

What it does:
- Returns all courses the user has enrolled in.
- Includes progress percentage and course status (JUST_ENROLLED, IN_PROGRESS, COMPLETED).

Input:
- Path Params:
  - user_id (required, string)

Output (UserEnrollmentsResponse):
- user_id: string
- enrolled_count: int
- enrolled_courses: [
    {
      course_id: string,
      title: string,
      progress_percentage: int (0-100),
      status: string (JUST_ENROLLED | IN_PROGRESS | COMPLETED)
    }
  ]

====================================================================
3) ENROLL IN COURSE
====================================================================
Method: POST
Path: /enroll
Full Endpoint: /api/courses/enroll

What it does:
- Enrolls user into a course.
- Validates plan status and course limit from UI-provided payload.
- Blocks if user already reached limit.

Input Body (EnrollmentRequest):
{
  "user_id": "string",
  "course_id": "string",
  "planType": "GOLD | SILVER | ...",
  "status": "ACTIVE | TRIAL | INACTIVE",
  "coursesLimit": 10
}

Output (ApiStatusResponse):
- status: string (ENROLLED or ALREADY_ENROLLED)
- message: string

6) LIST TOPICS IN MODULE
====================================================================
Method: GET
Path: /{course_id}/modules/{module_id}/topics
Full Endpoint: /api/courses/{course_id}/modules/{module_id}/topics

What it does:
- Returns topics under a module.
- Includes locked flag and user-specific status.

Input:
- Path Params:
  - course_id (required, string)
  - module_id (required, string)
- Query Params:
  - user_id (required, string)

Output (ModuleTopicsResponse):
- course_id: string
- module_id: string
- user_id: string
- topics: [
    {
      topic_id: string,
      title: string,
      description: string,
      duration_minutes: int,
      locked: bool,
      status: string
    }
  ]

7) UPDATE TOPIC PROGRESS
====================================================================
Method: PUT
Path: /{course_id}/modules/{module_id}/topics/{topic_id}/progress
Full Endpoint: /api/courses/{course_id}/modules/{module_id}/topics/{topic_id}/progress

What it does:
- Updates topic progress status for a user.
- Recalculates enrollment-level course progress.

Input:
- Path Params:
  - course_id (required, string)
  - module_id (required, string)
  - topic_id (required, string)
- Body (TopicProgressRequest):
{
  "user_id": "string",
  "status": "NOT_STARTED | IN_PROGRESS | STARTED | COMPLETED | ENDED"
}

Output (ApiStatusResponse):
- status: string (UPDATED)
- message: string
